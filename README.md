## 🚀 Featured project: [Wayfinder: AI Travel Planner](https://github.com/sanchitks/wayfinder-ai-travel-planner)

An AI travel planner for India where **four AI agents work in parallel**: an Orchestrator, plus Logistics, Accommodation and Experience agents. Together they plan flights and IRCTC trains, hotels and a day-by-day itinerary within your rupee budget.

<a href="https://github.com/sanchitks/wayfinder-ai-travel-planner"><img src="https://raw.githubusercontent.com/sanchitks/wayfinder-ai-travel-planner/main/docs/screenshots/itinerary.jpg" alt="Wayfinder itinerary screenshot" width="100%"></a>

- 🤖 **Multi-agent AI:** LangGraph agents powered by Claude. Live agent progress streams to the page, and a request like "find a cheaper hotel" re-runs only the agent it concerns.
- 🌐 **Real data:**
  - live flight fares in ₹ and Indian Railways options;
  - real hotels with live prices from Agoda and Booking.com;
  - real sights and restaurants (pure-veg, Jain and non-veg);
  - road routes on an interactive map.
- 🔐 **Full-stack features:** email and Google sign-in, profiles that pre-fill each trip, automatically saved trips, an admin panel with visitor analytics, and privacy controls.
- 📱 **Responsive** on phones, tablets and desktops, with light and dark themes.

**Stack:** Next.js · React · TypeScript · Python · FastAPI · LangGraph · Claude API · SQLAlchemy · Leaflet
